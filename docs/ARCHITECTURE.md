# 架构说明（公开版）

> 本文档为项目公开架构说明。内部交接细节（账号状态、真实 JWT、投递统计等）不在此仓库维护。

## 整体流程

```
用户配置筛选条件
      │
      ▼
Vue3 前端（frontend/）──HTTP/JSON──▶ FastAPI 后端（backend/）
                                        │
                        ┌───────────────┼───────────────┐
                        ▼               ▼               ▼
                   职位搜索        批量投递        自动跟进
              （Playwright）  （Playwright）   （Playwright）
                        │               │               │
                        └─────── SQLite 数据库（本地）───┘
```

- 后端通过 Playwright 驱动真实浏览器访问 Boss 直聘，模拟人工操作。
- 登录态持久化在浏览器 profile 中，扫码一次后长期有效。
- 投递任务在后台线程运行，前端轮询任务状态接口展示实时进度。

## 核心模块

| 模块 | 职责 |
| --- | --- |
| `app/api/apply.py` | 搜索 / 投递任务编排、任务状态、今日统计 |
| `app/api/auth.py` | 本地账号注册/登录（JWT）、管理员初始化 |
| `app/api/platform.py` | 平台会话管理（登录状态检测、扫码入口） |
| `app/core/boss/scraper.py` | Boss 职位搜索（API 快路径 + 页面回退、标题过滤） |
| `app/core/boss/applier.py` | 投递执行器（筛选终检、打招呼、防封节奏） |
| `app/core/boss/auth.py` | 登录态检测与账号信息获取 |
| `app/core/boss/followup.py` | 聊天页自动跟进扫描 |
| `app/services/followup_service.py` | 跟进结果落库与统计 |
| `frontend/src/views/*` | 前端页面（登录、平台授权、搜索、任务、记录、简历、看板） |

## 关键设计

### 搜索
- 优先走 API 快路径（POST `/wapi/zpgeek/search/joblist.json`），单页 0.5s 左右；遇风控 code=37 自动导航刷新 + 冷却后重试，并回退到页面加载路径。
- 全局节流控制请求频率，降低风控触发概率。
- 结果做多级过滤：关键词命中、标题排除词（标注/测试/销售等）、实习/猎头岗排除、地区白名单、休息制度匹配。

### 投递
- 支持 `rest_policy`（双休/大小周/单休）终检，打开职位详情页确认休息制度后再打招呼。
- 模拟人工节奏：详情页浏览停留 → 打招呼 → 聊天页停留 → 随机延迟。
- 每日名额上限（默认 150），用尽自动停止；已投职位/公司自动去重。

### 防封与风控
- 全程使用真实浏览器（Firefox）+ 持久化 profile，不使用无头模式投递，便于人工处理滑块验证。
- 参数可在 `backend/app/config.py` 或 `.env` 调整（延迟区间、日上限、停留时长等）。

## 数据存储

- 默认 SQLite：`backend/job_auto.db`（可通过 `.env` 切换 MySQL）。
- 主要表：用户、平台会话、投递任务、投递记录、简历、过滤规则。
- 数据库不纳入版本控制，首次启动自动建表。

## 通知通道（可选）

- 支持通过 QQ 开放平台机器人推送投递结果，配置说明见 `docs/QQ_BOT_SETUP.md`。
- 未配置时自动跳过，不影响核心功能。
