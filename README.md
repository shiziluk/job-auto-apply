# 牛人Agent - 智能求职投递系统

> 面向 Boss 直聘的职位搜索 / 打招呼 / 批量投递自动化工具（个人学习项目）。

## ⚠️ 重要说明：本项目当前不是智能体

项目名称中带有 **Agent**，但**当前版本尚未接入任何 AI 能力**（无 LLM、无模型调用），
实际实现是**规则化的自动化脚本**：按设定的关键词/城市/薪资/经验/学历/公司规模/休息制度
自动搜索职位并模拟人工完成打招呼投递。

- 不包含：大模型推理、智能问答、自动决策、自动跟进对话。
- 规划中：后续版本计划接入 AI 能力（如智能筛选、自动回复、跟进话术生成等），届时再如实更新说明。
- 因此，请勿将当前版本宣传为"AI 智能体"，README 与实际能力保持一致。

---

## 功能特性

- **多条件职位搜索**：关键词（支持多个）、城市（支持多城市）、薪资区间、经验、学历、公司规模、休息制度（双休/大小周/单休）。
- **智能过滤**：自动过滤已投递职位/公司、实习/日结岗、猎头岗、HR 长期不活跃、标题明显不相关的岗位（如标注/电销/产品/运营/销售等）。
- **批量打招呼**：按日名额上限自动投递，支持实时任务进度查看。
- **多岗位方向适配**：既支持 AI 应用开发/AI Agent 开发类岗位，也支持销售、AI 产品经理等岗位（按关键词自动切换过滤强度）。
- **防封策略**：模拟人工节奏（打开职位页浏览停留、打字间隔、随机延迟），降低被平台风控判定的概率。
- **自动跟进**：定期扫描聊天页，把 HR 回复/约面/拒绝/Offer 同步到本地记录。
- **桌面版**：PyInstaller 打包为桌面应用，双击启动后自动拉起后端服务并打开 Web 界面。

## 技术栈

| 层 | 技术 |
| --- | --- |
| 后端 | Python 3.11 + FastAPI + SQLAlchemy + SQLite |
| 前端 | Vue 3 + Vite + Pinia + Element Plus |

## 项目结构

```
├── backend/                  FastAPI 后端
│   ├── app/
│   │   ├── api/              接口路由（登录/搜索/投递/跟进/简历）
│   │   ├── core/boss/        Boss直聘适配器（搜索、投递、自动跟进）

│   │   ├── config.py         配置（支持 .env 覆盖）
│   │   └── database.py       SQLite/MySQL 连接

│   └── requirements.txt
├── frontend/                  Vue3 前端
│   └── src/
│       ├── views/            页面（登录/平台授权/搜索/任务/记录/简历/看板）
```

> 注：数据库（含投递记录、简历）、浏览器登录态、Cookie、上传文件、日志等运行数据均不纳入版本控制，见根目录 `.gitignore`。

## 快速开始（本地开发）

```bash
# 1. 后端
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --host 127.0.0.1 --port 8000

# 2. 前端
cd frontend
npm install
npm run dev
```

打开 http://localhost:5173 ，先在「平台登录」页扫码登录 Boss 直聘账号，再配置筛选条件发起搜索与投递。

### 首次使用

- 初始化管理员账号（默认 `admin / admin123`，请尽快修改）：

```bash
curl -X POST "http://127.0.0.1:8000/api/auth/init-admin?username=admin&password=admin123"
```

- 可选：复制 `backend/.env.example` 为 `backend/.env` 并按需调整（端口、每日投递上限、防封延迟、QQ 通知等）。

## 使用流程

1. **登录**：扫码登录 Boss 直聘（登录态持久化，无需重复扫码）。
2. **搜索**：设置筛选条件（关键词/城市/薪资/经验/学历/规模/休息制度），点击搜索。
3. **投递**：勾选职位发起批量投递，任务在后台执行，可实时查看成功/失败/跳过与剩余名额。
4. **跟进**：开启自动跟进后，系统定期同步 HR 回复状态。

## 防封节奏

- 打开职位详情页后模拟浏览 **5~10s**（滚动阅读 JD）再点「立即沟通」。
- 打招呼后在聊天页停留 **6~9s**。
- 职位间随机延迟 **4.5~7.5s**。
- 日打招呼上限默认 **150**（可在 `backend/app/config.py` 或 `.env` 调整）。

## 桌面版（可选）

```bash
cd backend
pip install pyinstaller
pyinstaller 牛人Agent.spec
```

产物在 `backend/dist/` 下，双击 `牛人Agent.exe` 即可：自动初始化数据目录（`%APPDATA%\牛人Agent`）→ 启动后端 → 打开 Web 界面。

## 安全与隐私

- **默认凭据**：本地管理后台默认 `admin / admin123`，部署到公网前务必修改。
- **密钥**：`SECRET_KEY`、数据库密码等只放在本地 `backend/.env`，已被 `.gitignore` 排除，切勿提交。
- **运行数据**：SQLite 数据库、浏览器登录态（`.browser_data`）、Cookie、上传的简历、日志均不纳入版本控制。
- **账号风险**：自动化打招呼可能触发平台风控，请合理控制频率与日名额，后果自负。
